# Optional compact CGA choices

The consumer installer offers six visible choices. `320` and `640` keep
their accepted fonts and controls; `320C` and `640C` select the CGA100 compact
UI at the same fixed resolution. Enter cancels without changes. See the
[consumer instructions](../../docs/CGA.MD) and
[preparation/build commands](../../src/cga/README.MD).

The two added drivers contain the exact accepted CGA100 OEM bitmaps and
font/config descriptors. Their normal-mode palettes and all ten file-backed
renderer/data segments, including relocations, stay byte-identical.
Consumers receive complete native drivers and fonts; resource generation is
part of the developer producer.

`docs/QUAL/CGACMP/BASE.*` freezes the actual preceding current CGA packet,
including its public PAN dispatcher and all seven unchanged helper binaries.
`SRCPAN.ZIP` retains eight original sources with their original acceptance
hashes. `HISTORY.PY` allows only those exact superseded identities to reproduce
the earlier packets. The original PAN acceptance records, native results and
review are unchanged. Its core producer still reproduces all four core assets
with their original metadata; old packet composition uses its original guide.

The current alternative boundary sends a changed CGA ZIP through `VERIFY.PY`.
That gate requires exact native build/heap, menu/switch/UNDO, actual installed
payload, both Windows applications/save/normal-DOS-return, lease cleanup and
independent source/packet review evidence. A catalog checksum or a successful
host test cannot accept a new runtime. `ACCEPT01.JSN` in the qualification
folder retains the acceptance sealed from the clear re-review of `902526c`.
Integration with current main changes only its producer-history dispatch;
active `ACCEPT.JSN` is pending final integration review of that source change.
All 18 source identities and the unchanged native packet remain bound.

```text
python tools/PAN/GATETEST.PY --out NEW-PRIOR-GATE.JSN
python tools/CGACMP/TEST.PY --out NEW-COMPACT-GATE
python tools/CGACMP/VERIFY.PY --candidate docs/QUAL/CGACMP/CANDIDATE.JSN
python tools/CGACMP/VERIFY.PY
```

The candidate command checks completed native evidence and exact current
source bindings. The normal verifier also requires sealed independent review;
the local catalog remains refused until the final integration review is sealed.

The gate parses the exact launch configuration rather than trusting its
machine declaration. Its closed recorded fixture requires the 8088 at
4,772,728 Hz, multiplier 1, IBM XT, 640 KB and CGA, with dynarec disabled.
Additional sections/options (including memory boards and memory overrides),
inherited defaults, duplicate options and malformed configurations are refused.
Host negative checks restamp changed config/result hashes while keeping the
XT/640 KB declaration unchanged, reproducing the first independent finding.

Do not replace `downloads/PAN/CGA.ZIP`: it remains the immutable preceding
packet. A qualified compact alternative uses a separate tracked path and an
updated local catalog entry, as prepared here. The new HPDIB core from main
is reproduced exactly; each historical snapshot keeps its own closed names
and original identities. See `docs/QUAL/CGACMP/INTEG.JSN`. Publication requires explicit approval,
exact-source review and current CI. Physical hardware remains unqualified.
