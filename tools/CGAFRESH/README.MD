# Fresh CGA catalog gate

`VERIFY.PY` accepts one exact integrated CGA archive after original-media
Setup entry, completed installation, first ordinary `WIN /R` startup and
normal DOS return. It also requires the exact native-tested launcher,
accepted installed display support, a closed nine-member source archive,
matching source-rebuild/refusal results, bounded native cleanup and an
independent review of the final production source map.

`ACCEPT.JSN` is a local evidence receipt, not publication authorization.
`TESTGATE.PY` checks altered archives/evidence, incomplete completion/startup,
changed launcher/source inputs, unsafe paths and unsupported memory claims.
Neither script starts an emulator or makes a network request.
Before final review, `TESTGATE.PY --candidate --out NEW-OUTPUT` checks the
source/native candidate without accepting it for catalog use. The catalog
always calls `verify`, which requires the completed independent review.

The current catalog calls this new gate first. It then passes a **copied**
asset map with only `CGA.ZIP` replaced by the immutable accepted compact base
to the unchanged HPDIB/PAN verifier. Actual output bytes remain the new
integrated packet. The current catalog refuses the old CGA archive, while
historical producers and native receipts retain their original contracts.
The four qualified Tandy core identities are unchanged.

Developer reproduction uses `src/cga/FRESHPK.PY` and `FRESHT.PY`. The
integrated runtime is stored as `downloads/FRESH/CGA.ZIP` and its standalone
launcher rebuild source as `downloads/FRESH/CGASRC.ZIP`. The source package
contains project inputs only; no operating system, DDK/compiler, emulator or
guest image is included. Current curation uses `tools/CURRENT/BUNDLE.PY` and
`CHECK.PY` with the existing qualified core and sound inputs.

Keep the earlier Setup-entry receipt unchanged. Completion is a separate
receipt linked to that entry and to the reused private image; source support
and selected boot entries are verified again after the normal first start.
Physical hardware, other fresh profiles and a full floppy-swapping sequence
remain separate qualification. No publication occurs without Chad's approval.
