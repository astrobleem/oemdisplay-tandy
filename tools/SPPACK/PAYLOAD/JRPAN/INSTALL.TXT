JRPAN SOFTWARE PANNING - WINDOWS 3.0 REAL MODE

320x400 logical desktop through a 320x200 viewport, 16 colors.
Software copies present the viewport; this does not add hardware panning.
The shadow uses 64,000 bytes, 32,000 more than the fixed driver.
Emulator-tested on DOSBox-X PCjr, 640 KB.

INSTALL
1. Extract JRPAN.ZIP to C:\ so this folder is C:\JRPAN.
2. Exit Windows to DOS and run C:\JRPAN\INSTALL.
3. In Setup choose Display, Other, C:\JRPAN, then
   EXPERIMENTAL IBM PCjr 320x400 software panning.
   Return to DOS when Setup finishes.
4. Start Windows with C:\JRPAN\JRSTART. In File > Run, run
   C:\JRPAN\PANCFG. It starts the helper and enables later startup.
The PCjr DOS memory driver must reserve its 32 KB video page.
INSTALL and JRSTART run JRGUARD before proceeding.

USE
Move the pointer beyond the viewport or dwell at its upper/lower edge.
Alt+PgDn pans down; Alt+PgUp pans up; Alt+F9 returns to the top.
Newly activated windows are brought into view.

RETURN TO FIXED 320x200
Run C:\JRPAN\PANCFG OFF from Windows File > Run. Exit Windows,
run C:\JRPAN\INSTALL again, and select Display, Other, C:\JRPAN,
then IBM PCjr 320x200 fixed (rollback).
Continue using C:\JRPAN\JRSTART to start Windows.
