CPPAN SOFTWARE PANNING - WINDOWS 3.0 REAL MODE

320x400 logical desktop through a 320x200 viewport, 16 colors.
Software copies present the viewport; this does not add hardware panning.
The shadow uses 64,000 bytes, 32,000 more than the fixed driver.
Emulator-tested on 86Box XT/Plantronics, 640 KB, PC DOS 3.20.

INSTALL
1. Extract CPPAN.ZIP to C:\ so this folder is C:\CPPAN.
2. Exit Windows to DOS and run C:\CPPAN\INSTALL.
3. In Setup choose Display, Other, C:\CPPAN, then
   EXPERIMENTAL ColorPlus 320x400 panning.
   Return to DOS when Setup finishes.
4. Start Windows with C:\CPPAN\CPWIN. In File > Run, run
   C:\CPPAN\PANCFG. It starts the helper and enables later startup.
The required CGA.GR2, fonts, logos and helper programs are included.
INSTALL stages the supplied grabber and display driver before Setup.

USE
Move the pointer beyond the viewport or dwell at its upper/lower edge.
Alt+PgDn pans down; Alt+PgUp pans up; Alt+F9 returns to the top.
Newly activated windows are brought into view.
Run C:\CPPAN\PANCFG SETTINGS for step, edge, dwell and window-follow settings.
Apply saves changes; Cancel discards edits. Reopening reuses the same helper.

RETURN TO FIXED 320x200
Run C:\CPPAN\PANCFG OFF from Windows File > Run. Exit Windows,
run C:\CPPAN\INSTALL again, and select Display, Other, C:\CPPAN,
then ColorPlus 320x200 fixed (rollback).
Continue using C:\CPPAN\CPWIN to start Windows.
