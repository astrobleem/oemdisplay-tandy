MINESWEEPER - WINDOWS 3.0 REAL MODE

1. Extract every file from MINESET.ZIP together into C:\MINETST, or your chosen folder.
2. Start your normal guarded Windows desktop.
3. In Tandy Start Run, or Program Manager File / Run, enter:
     C:\MINETST\MINERUN.EXE
   Use your chosen folder if different. Use MINERUN for later launches too.

Keep MINERUN.EXE, WINMINE.EXE and WMABT.DLL together. MINERUN loads the app-local
About helper before starting the game. No global DLL copy or INI change is needed.
Left click reveals, right click flags, F2 starts a game. Close the app normally.
If another WMABT is already loaded, exit and restart Windows before using MINERUN.
To remove the app, close it and remove its private folder.
The game, helper and launcher bytes match the native-qualified packet.
