# Historical source bindings

SOURCES.ZIP contains only the explicitly listed superseded source files from
main d6fb0fc70133a0210fd0ed476b88224df5f17dd9. SOURCE.PY verifies the archive
hash, exact member inventory and original caller-provided per-file pins.
Runtime payloads and native evidence remain live inputs with their original pins.
This preserves historical qualifications while current UPAN acceptance validates
the replacement helpers and catalog. No historical packet or pin is restamped.

Run python -B tools/LEGACY/TEST.PY for fallback and refusal checks.
