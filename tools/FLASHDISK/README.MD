# Windows XT fixed-profile data disk

The current generator includes the validated expanded CGA.GR2 with seven
original fonts, the static startup logo and the accepted fixed-profile
runtime. DOS/Windows itself remains required and is not redistributed.
No matching support-media directory is needed on the vintage computer.

Run INSTALL from the 720 KB data disk, confirm preparation, then run
C: / CD \WINXT / INSTALL. Windows Setup selects the display profile.
Start sessions with C:\WINXT\WINXT so its guards run. Full consumer steps
are generated by MAKEIMG.PY into both the outer and staged README.TXT.

## Reproduce and verify

Use a new output directory; no compiler or emulator is started:

```text
python -B tools/FLASHDISK/MAKEIMG.PY --out NEW-DIRECTORY
python -B tools/FLASHDISK/TESTPKG.PY --verify NEW-DIRECTORY
python -B tools/FLASHDISK/TESTPKG.PY
```
