PREPXT - WINDOWS XT FIXED-PROFILE PREPARATION

At the 720 KB data disk root, run INSTALL from plain DOS. The packet includes
CGA.GR2, seven original fonts and the original startup logo. No separate
Windows support-media folder is needed. An installed Windows 3.0 remains
required; this data disk contains no DOS/Windows installation media.

Advanced syntax for a different installed Windows directory:
  PREPXT WINXT D:\WINDOWS

PREPXT stages a fresh C:\WINXT after its checks and your Y confirmation.
Then select C:, CD \WINXT and run INSTALL with that same Windows path.
The helper never starts Setup itself. Its existing no-overwrite, free-space,
bounded input and I/O checks remain. /VERIFY enables deeper diagnostics.

Preparation checks the included grabber first. Executable code is unchanged;
current resource/document pins are bound to the complete packet. Native
preparation, both supported metadata inputs and guarded startup are recorded
in tools/FLASHDISK/CURRENT.JSN in the source repository. Historical receipts
retain their original byte and test scope.
