PREPXT - ORIGINAL XT PIXELS FONT TEST CANDIDATE

DOS 3.3+, 8086/8088, 640 KB. Exit Windows before preparation.
At disk root: INSTALL [owned-media directory]. Advanced:
  PREPXT WINXT C:\WINDOWS [media-dir1 ... media-dir4] [/VERIFY]

Only CGA.GR2 (2104 bytes) and CGALOGO.LGO (880 bytes) require matching owned
Windows media. Seven MIT-licensed fonts are public original runtime files.
There is no mandatory Windows-font hash, private-font transplant or vintage
Python dependency. Other non-font Windows dependencies remain.

Default copying performs zero SHA checks; bounded decompression, size and
I/O checks remain. /VERIFY enables slow deep checks and readbacks. Do not
make /VERIFY the default on vintage hardware. All inputs remain read-only.
The output must be fresh C:\WINXT. INSTALL.BAT is committed last after safe
copy/close checks. Existing output, missing inputs, malformed data, low space
and declined confirmation are refused. PREPXT never starts Windows/Setup.

After success, C: then CD \WINXT then INSTALL. Setup owns display/font
installation; the generated WINXT launcher and numbered backup own guarded
start/switch and rollback. See the disk README and CPSET.TXT. No publication
is authorized. This source workspace has no rebuilt PREPXT.EXE or HELPER.SHA
until the approved compiler and subsequent native/host checks pass.
