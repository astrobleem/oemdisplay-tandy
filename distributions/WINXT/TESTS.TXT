FINAL SHARED-ROOT INTEGRATION: SIX OF SIX PASS
Six fresh stock-CGA Windows 3.0 installations on genuine guest MS-DOS 6.22
were installed using INSTALL and unmodified native Windows DOS SETUP.
Every profile used only C:\WINXT at both Other-display and copy prompts.
All six driver/font selections matched the pinned source bytes. Optional
TSSETUP then installed its three verified files without permanent shell edits.

Fresh emulator boots through the one C:\WINXT\WINXT command reached:
- Five TR5 graphics modes: qualified TSHELL14 desktop, real-mode flags 64.
- Experimental TXTMODE: original Program Manager, real-mode flags 64.
Every case returned to genuine DOS through native keyboard exit, with exact
post-Setup SYSTEM.INI restored after the temporary shell session. No TDISPLAY,
TANDY88, TSTART or root-level numbered-backup directory was created.

TEXT -> GRAPHICS -> FULL RECOVERY: PASS

saved ROOT/SYSTEM file, preserved the shell marker as SHREADY.OFF and cleared
active selector transactions. A fresh WINXT launch used original stock-CGA
Windows/Program Manager; native exit retained exact original SYSTEM.INI,
WIN.INI and WIN.COM. All recovery helpers retained the RESERVE safety path.
