WINDOWS XT - CURRENT DOWNLOADS

Windows XT desktop or drivers only:
https://github.com/astrobleem/oemdisplay-tandy/releases/download/windows-xt/WINXT.ZIP
Extract SETUP.EXE, README.TXT and the WINXT folder together.
From DOS run SETUP UPDATE C:\WINDOWS, or SETUP FRESH A:\ with the first
original Windows disk. The installer gathers Windows OS files automatically.
Start later full-desktop sessions with C:\STARTXT.
For drivers only, use the same WINXT folder in Windows Setup instead.
