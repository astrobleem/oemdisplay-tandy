# Tandy Video II display

[Download TNDYV2.ZIP](TNDYV2.ZIP?raw=1), extract to `C:\T2EXP` and follow
[installation](../../../docs/tga2/INSTALL.TXT). Fonts, grabber and startup
logo are included. Run `C:\T2EXP\INSTALL` once, then
`C:\T2EXP\T2WIN` for every launch. Both reserve video memory automatically
and stop if reservation fails. For SL/2-family Video II, not EX/HX.
