EXJOY 1.0 verification, 2026-10-04

Fresh publication checks
- C6/MASM/LINK4 /G0/.8086 build, zero warnings/errors, byte-identical to the tested 9487-byte EXE. SHA256 cde3fb792d9cd80062562410cf9fa4d6ccfcdb597b30ecbad6b220a7e3984893.
- 90060 independent host checks with ASan/UBSan, leak detection off: boundary/timeout/early pulse cases, all button masks, 10000 randomized pulse quartets, calibration/normalization and invalid center reset.
- CAPTEST.PY on exact assembled reader bytes: 128 simulated-I/O cases, one OUT and exactly 512 IN at 0201h, 2063 modeled instructions, bounded buffer writes and register/stack restoration. This is structural boundedness, not physical timing proof.
- AUDIT.PY: 2814 reachable instructions, no post-8088 suspects; Windows imports/indirect paths excluded.

Reproduce
cc -std=c89 -pedantic -Wall -Wextra -Werror -fsanitize=address,undefined -g -I . -x c HOSTTEST.C JOYCORE.C -o hosttest
ASAN_OPTIONS=detect_leaks=0 ./hosttest
python3 CAPTEST.PY NEW_BUILD/EXJOY.EXE
python3 AUDIT.PY NEW_BUILD/EXJOY.EXE
Both Python checks require the matching .MAP generated by BUILD.PY.

Retained native evidence
Disposable Windows 3.0 real-mode tests at 160x200 color and 640x200 mono passed create/timer, synthetic input with no I/O, center/normalization, pause/resume, reset and clean destruction/DOS return. A no-device emulator run performed 30 bounded production polls with raw FF, timeout mask F and no buttons. This does not prove a disconnected physical EX port returns those values. 640 KB, no XMS/EMS/UMB, 8086_prefetch, uncalibrated 5000 cycles, DOSBox internal DOS. TESTWIN.PY supports reproduction with lawful owned guests; developer test modes exit Windows.

Physical EX joystick behavior, connector mapping, electrical endpoints and absolute timing remain untested. Interrupts stay enabled; counts can jitter and are not elapsed-time units. MAX_POLL_MS=0 in earlier logs meant coarse-timer resolution, not zero duration. The interface makes no automatic presence claim. No OS, ROM, toolchain, guest image, private receipt or recording is included.
