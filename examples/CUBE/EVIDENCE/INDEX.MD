# Evidence scope

ACCEPT.JSN selects the current native receipts and pins every evidence file.
Only the roles in ACCEPT.native qualify the current four-file runtime.

The corrected Cube has SHA-256
`9ce367edd179291f324b011f8175afa90d298d1c60a644ef53d63ae56b43aa0e`.
Its current native folders are UI04, LOW02, MONO02, TANDY03, PAN02,
CGAPAN02, T6404-02, CGA32002 and T160-02. A folder is included as current
only after its completed PASS receipt and verified process/lease release.

BUILD contains native build receipts, the first-party source/runtime binding,
installer source/header binding and scoped ISA audit. External compiler/SDK
identities remain in the individual build receipts; those inputs are excluded.
HOST/RESULT.JSON is the corrected five-group host run. HOST/LIFECYCLE.JSN
records its production-code API-spy control. Older HOST/RESULT.JSN is history.

INDEPENDENT retains original source/package findings and correction reviews.
The frozen CUBE-BEFORE.C control fails the teardown activation policy; current
production code passes. NATIVE-SMOKE-NONDISCRIMINATING.JSN explicitly records
that an earlier native settling test passed old code and did not reproduce
the focus symptom. The corrected UI04 observer is a native smoke test, while
the deterministic API-spy test discriminates the source correction.

Other native folders, earlier build/host records and failed receipts are
historical evidence. They are preserved, but do not qualify different runtime
bytes. The final independent review of the assembled ZIPs is stored beside
the immutable deliverables so the review can bind their exact hashes without
repacking them to include their own review.

Headless PNGs retain adapter-specific scaling. Decoded *-VRAM.PNG captures
show CGA logical RGBI cells with nearest-neighbor enlargement; neither form
claims calibrated physical aspect ratio, composite output or hardware coverage.

No OS image, installed Windows tree, ROM, SDK/compiler library, emulator or
third-party runtime belongs here. Lab harnesses retain their exact local paths
for provenance and need private owned fixtures to replay native acceptance.
