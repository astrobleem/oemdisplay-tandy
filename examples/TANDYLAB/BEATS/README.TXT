BEATS.EXE + MIDIMAP.DRV ARE ONE PRIVATE PAIR
===========================================
Keep both files in this folder and run BEATS.EXE inside Windows 3.0 real mode.
It loads the driver's path beside its own executable. Never copy MIDIMAP.DRV
into WINDOWS/SYSTEM or register it in SYSTEM.INI. No TSOUND installation is
required. Keep normal Windows SOUND support installed by Windows Setup.

Only one PSG sound app at a time. Close Mouth, chimes, PSGPLAY and other
sound tools before Play. P plays, S/Esc stops; close normally after Stop.
Click an eight-step cell or use the native controls to change the pattern.
Patterns are not saved. This is a direct-driver sequencer experiment, not
a system MIDI dispatcher, MIDI-file player or physical MIDI interface.
After a forced task termination, restart Windows if sound ownership is stuck.
