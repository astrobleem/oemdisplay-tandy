SOURCE / PROVENANCE / NOTICES
=============================
This is a curated runtime layout of previously sealed first-party projects.
Existing runtimes are unchanged. CDSTART is a new tiny launcher for private
COMMDLG lookup; its complete first-party source is EXPER/CDLG/SOURCE.ZIP.
SHA256 pins
are checked while packaging; MANIFEST.SHA describes the resulting files.
Application detailed README text is preserved in DOCS (line endings and en-dashes normalized for DOS).
Their source/build/evidence directories live in the original source packages,
not in this runtime-only pack. No new project-wide license claim is made.
