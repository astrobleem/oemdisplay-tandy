TSHELL - RUN AS AN ORDINARY APP FIRST
====================================
Launch this TSHELL.EXE from Program Manager using its full path. Start /
Run / Browse can locate any TANDYLAB app without moving it into WINDOWS.
The fixed menu's demo entries use Windows/PATH lookup, so gray entries are
expected with this deliberately private-folder layout. Use Run/Browse.
Close bar removes only TSHELL. Keep Program Manager as the Windows shell.
No SYSTEM.INI or startup edits are needed. No COMMDLG DLL is required.
TSHELL's Exit Windows uses ordinary Windows exit, not the TEXIT chime.
