OPTIONAL EXPERIMENTS - TEST LAST
===============================
CDLG: original bounded COMMDLG compatibility subset plus its paired CDTEST.
Keep its DLL app-local. Do not install it system-wide. Native automated
suites passed; real mouse/keyboard and third-party-app compatibility remain
untested. Use new scratch output names and close unsaved work first.

MAZE: windowed raycasting proof, not an idle saver. Approximate-XT tests
were extremely slow, including about 87 seconds to first paint. A long
initial delay is a known limitation. Physical speed is not established.

TEXTMODE hardware character driver is not included. That separate lab
proof has known character loss/redraw failures and transforms owned font
inputs. It must not replace the new working graphics setup.

The BEATS folder is also an experimental preview, isolated by design.
