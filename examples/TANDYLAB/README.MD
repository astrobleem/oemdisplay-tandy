# TANDYLAB applications

[Download TANDYLAB.ZIP](https://github.com/astrobleem/oemdisplay-tandy/releases/download/windows-xt/TANDYLAB.ZIP) and extract its `TANDYLAB` folder
to your DOS computer. Use installed Windows 3.0 real mode and your normal
guarded Windows startup. In Program Manager File / Run, start
`C:\TANDYLAB\ABOUT\TABOUT.EXE`, or choose an app from `CATALOG.TXT`.
Use the actual extraction drive and folder if different. Keep each app's files together.

The optional `DRIVERS\WINXT` folder is a complete Windows Setup source for
original Tandy EX/HX with normal 640 KB. From that folder in DOS run `DISPLAY`,
choose Display / Other in Windows Setup, and enter that same folder's full path
at its driver-disk prompts. Select HPXY and complete changes. For each launch,
change to that folder and run `DISPWIN`; reservation is automatic.
Fonts, grabber, logos and helpers are included. There is no Python staging step
or individual support-file collection. [Display instructions](../../docs/DRIVERS.MD).

This current packet keeps the collection's application bytes unchanged and
replaces its old optional toolkit with the exact current expanded driver files.
Its historical app tests and physical-hardware limits remain in the [catalog](CATALOG.TXT),
folder notes and [source records](EVIDENCE). It does not qualify new game behavior.
The original sealed archive and verifier remain source-reproduction records.
