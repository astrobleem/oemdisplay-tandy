FINAL COMMON-ROOT INSTALL
Genuine DOS 6.22, Windows 3.0 WIN/R, Tandy 8086, 640KB, no XMS/EMS/UMB.
Fixtures began with Program Manager selected, stock keyboard, no active shell
EXE/DLL/INI, and no previous support folder. The tested root is C:\WINXT,
with active files in C:\WINDOWS. TR41616 and TR36402 were installed by the
private fixture; the combined display installer's separate six-mode tests
qualify its new drivers and common launcher.

- Fresh 160 and 640 installs succeeded. Both original Windows INIs were backed
  up byte-for-byte under WINXT\BACKUP\SHELL14, and all three installed files
  matched the supplied files. SHREADY.TAG matched its template; NEW was absent.
- Repeating TSSETUP refused the existing marker/files without overwriting them.
- At 160, About launched from the new root. Cancel preserved Windows, then
  normal TEXIT/go exit returned to DOS and drew the success-only moon screen.
- At 640, My Computer opened stock File Manager. Its normal exit confirmation
  worked. Save Settings was unchecked for the fixture. Run opened Notepad;
  its unsaved-file prompt appeared on Shift and normal exit attempts. Cancel
  vetoed the Shift exit. A normal chime exit later returned to DOS after
  discarding only fixture text.
- A second 640 launch through TSTART recovered cleanly and started again.
  Matrix, Maze and Starfield each launched from C:\WINXT and returned to the
  settings dialog. Cancel retained the original settings. Shift at Exit
  selection skipped TEXIT on this second launch; the log contains no TEXIT
  module load in that session. Windows returned to DOS with the moon screen.
- SYSTEM.INI and WIN.INI matched their original bytes after the final returns.
  No TSHELL.JRN, NEW, OLD or RST active transaction remained. Persistent
  TSHELL.BAK/SAV were retained, as designed.

LIMITS
These are functional emulator tests, not physical timing or audio-output
measurements. The stock keyboard intentionally leaves automatic Hold off.
The separate compatible keyboard kit and physical Windows Hold confirmation
remain opt-in/pending. Experimental text mode is not a qualified TSHELL target;
the common launcher retains the original shell there. No OS images, SDK,
compiler or user-card content are redistributed with this evidence.
