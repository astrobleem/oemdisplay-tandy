WINDOWS 3.0 / 8086 RUNTIME DISPLAY PROBES
======================================

These standalone, no-dialog Win16 programs were built with CL /G0 /Gw
/AS /W3 /Od and a MASM .8086 BIOS helper. LINK4 uses the supplied
SLIBCEW.LIB and LIBW.LIB. The strict 8086_prefetch runtime executed the
minimal metrics probe successfully on the candidate04 Tandy driver.

PROBE.EXE: writes C:\PROBE.LOG and exits immediately. Reports screen
metrics, display-device caps, INT 10h/AH=0F current BIOS mode, cursor.

PROBECUR.EXE: writes C:\PROBECUR.LOG while pumping Windows messages
for 60 seconds. Records changed cursor positions at 250 ms intervals.
No window or modal dialog; stops automatically.

PROBEDRW.EXE: draws 16 palette strips, a one-pixel complete screen
border, and four distinct corner blocks. Dumps exactly 32768 bytes of
B800:0000 to C:\PROBEDRW.BIN. C:\PROBEDRW.LOG reports completion.
The updated probe hides the cursor until ShowCursor returns negative,
logs the count, calls SetCursor(NULL), and restores/balances afterward.

PROBEBLT.EXE: constructs a 32x16 compatible memory bitmap with a
16-color pattern. Tests 12 SRCCOPY transfers with varied odd/even
source and destination offsets and widths/heights. Writes
C:\PROBEBLT.LOG and a 32768-byte C:\PROBEBLT.BIN screen dump.
Uses the same cursor-hide/restore discipline.

Both graphical probes require 320x200, overwrite the visible desktop,
and exit without waiting. Run only in Windows 3.0 real mode: B800 is a
real segment, not a protected-mode selector. The desktop can be
repainted afterward. These are test programs, not driver components.

BUILD
-----
In DOSBox, mount the repository root as C: (BIN, LIB, DDK, INCLUDE),
copy PROBE*.C, PROBEASM.ASM, PROBE*.DEF, PROBE*.RSP, PROBEBLD.BAT to a
separate build directory mounted as D:, switch to D:, run PROBEBLD.
All input files use CRLF and 8.3 DOS names. Output PROBEBD.LOG must end
in PASS. The /G0 switch explicitly requests 8086 instruction generation.

INDEPENDENT RAW-FRAMEBUFFER CHECK
--------------------------------
Host Python requires Pillow. Copy each guest dump before running:
  python3 PROBEDMP.PY PROBEDRW.BIN --test draw --out draw-check
  python3 PROBEDMP.PY PROBEBLT.BIN --test blt --out blt-check
The checker compares all 64000 pixels and writes PNG plus JSON.
Mode09 offset = (y % 4)*8192 + (y // 4)*160 + x//2;
even x uses the high nibble. Expected patterns are generated directly
from the documented rectangles and formulas, independently of driver
code. Comparisons use physical color indices. The PNG uses the
standard physical palette; the requested logical RGB values match the
driver table (128-level dark colors, gray128, darkgray64).
