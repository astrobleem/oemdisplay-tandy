BUILD
The included ROUNDn.BAT uses CL /nologo /c /G0 /Gw /AS /W3 /Od and LINK4.
Copy ROUNDn.C, ROUNDn.DEF, ROUNDn.RSP, ROUNDn.BAT to the build directory.
The exact BUILDn.CNF structure (substitute n=2,3,4,5) is:

[sdl]
fullscreen=false
output=surface
[dosbox]
machine=tandy
memsize=16
working directory option=force
working directory default=/workspace/shared/tandy-roundtrip
[cpu]
core=normal
cputype=8086_prefetch
cycles=fixed 200000
[mixer]
nosound=true
[midi]
mididevice=none
[autoexec]
@echo off
mount C "/workspace/shared/tandy-savefix"
mount D "/workspace/shared/tandy-roundtrip"
D:
ROUNDn.BAT

Run:
SDL_VIDEODRIVER=dummy /workspace/shared/dosbox-x/run -nopromptfolder -conf /workspace/shared/tandy-roundtrip/BUILDn.CNF
Check BUILDn.LOG; the final authored probes compile/link without warnings.
Copy each ROUNDn.EXE into round05-c/WINDOWS.

EXACT FINAL RUNS
For n=2,3,4,5, RUN05n.CNF contains the runtime profile above with startn:
python /workspace/shared/tandy-roundtrip/ROUNDGO.PY /workspace/shared/tandy-roundtrip/RUN05n.CNF /workspace/shared/windows30/round05-c/ROUNDn.LOG --host-log /workspace/shared/tandy-roundtrip/final05n-host.log

ROUNDGO.PY captures at most 1 MiB of host diagnostics, drains remaining output,
waits for the flushed COMPLETE=1 marker, and stops only its isolated process.
It does not use process-wide file-size limits, which break SDL shared memory.
