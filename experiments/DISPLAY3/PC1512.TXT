PC1512.DRV - EXPERIMENTAL AMSTRAD PC1512 DISPLAY
640x200, 16 colors, Windows 3.0 real mode

This ZIP contains a ready-built driver, not Windows or a Setup disk.
Use a bootable backup/disposable clone of an existing Windows 3.0 install.
Retain a plain-DOS recovery route. Exit Windows completely before changes.
Normal hardware use and a fresh Windows Setup installation are unqualified.

TARGET
Amstrad PC1512 built-in four-plane 64KB video, 8086, normal 640KB RAM.
Not ordinary CGA, Tandy, PCjr or the PC1640's different video hardware.
No RESERVE/JRGUARD step: the PC1512 has dedicated video RAM.

INSTALL IN A CLONE
1. Extract the complete ZIP to a new C:\P15EXP directory. Verify SHA256.SUM
   on a modern host. Do not reuse an old backup directory.
2. Back up the complete Windows installation/image before continuing.
3. At plain DOS: COPY C:\WINDOWS\SYSTEM.INI C:\P15EXP\SYSBACK.INI
   Stop if SYSBACK.INI already exists. Record the old display.drv setting.
4. If C:\WINDOWS\SYSTEM\PC1512.DRV already exists, preserve its original
   bytes separately before copying this package's driver over it.
5. COPY C:\P15EXP\PC1512.DRV C:\WINDOWS\SYSTEM\PC1512.DRV
6. With a DOS text editor, change only the [boot] display.drv setting in
   C:\WINDOWS\SYSTEM.INI to display.drv=PC1512.DRV.
7. CD \WINDOWS, then WIN /R. Do not use the Tandy WINXT startup/reservation
   route or its palette animation for this experiment.

These fixed C:\WINDOWS paths describe the qualified cloned-install route.
For another Windows directory, substitute that directory consistently.
The original tests reused an AT/EGA install and its EGA fonts/grabber.
Keep that font/grabber configuration for the first reproduction. Fresh
CGA-class Setup/fonts/grabber integration and DOS boxes remain untested.
The driver package does not change keyboard or mouse configuration.

ROLLBACK FROM PLAIN DOS
Exit Windows fully, or reboot to DOS if Windows will not start.
COPY C:\P15EXP\SYSBACK.INI C:\WINDOWS\SYSTEM.INI
Restore a pre-existing PC1512.DRV if you replaced one. A newly added driver
may remain inactive after restoring the old setting. Restore the complete
image/installation backup if any additional configuration was changed.
Never share a completed guest or backup containing Windows/DOS files.

WHAT WAS TESTED / WHAT WAS NOT
Exact packaged driver bytes passed recorded Windows 3.0 checks in 86Box
6.0: 88/88 final checks, 15/16 palette cases first try, one recovery.
The rejected frame was a crosshair at the correct hotspot; its cursor-state
cause is unresolved. Host checks reject stale aliases and invalid evidence.
Physical PC1512 hardware, the native Amstrad mouse port, real timing,
fresh Setup and DOS/grabber switching are unqualified. Serial input was
emulated. A release is not a promise of general physical-machine support.
