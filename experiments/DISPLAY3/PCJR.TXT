IBM PCjr - CURRENT DOWNLOAD AND INSTALLATION

Use PCJRSET.ZIP for fresh Setup or an existing Windows 3.0 installation:
https://raw.githubusercontent.com/astrobleem/oemdisplay-tandy/main/downloads/experimental/PCJR/PCJRSET.ZIP
Extract PCJREXP to C:\PCJREXP. From plain DOS run C:\PCJREXP\JRGUARD.
Continue only after OK, then follow Windows Setup as described here:
https://github.com/astrobleem/oemdisplay-tandy/blob/main/src/pcjr/INSTALL/INSTALL.TXT
JRGUARD checks an already reserved 32 KB video page; it does not reserve RAM.
Start every Windows session with C:\PCJREXP\JRWIN.

WHAT WAS TESTED / WHAT WAS NOT
The exact driver previously booted Windows 3.0 in DOSBox-X PCjr emulation:
dialogs, Program Manager, Solitaire, exit and guarded restart.
That test reused an AT/EGA installation, EGA fonts/grabber, AT keyboard
setting and emulated serial input. It used DOSBox-X's internal DOS, not
physical PC DOS on an expanded PCjr. Saved groups/window positions can
look damaged or clipped after changing the display geometry.
Full Paintbrush save/reopen/ROP/frame-oracle coverage, fresh CGA-class
Setup, real memory expansions, keyboard/mouse paths, timing and physical
hardware remain unqualified. Use a nonanimated WIN.COM; Tandy palette animation
programs the wrong data port for a PCjr.
The new JRWIN launcher also passed 14 stub-Windows control cases, actual
guard acceptance/refusal, and two guarded real Windows 3.0 starts and normal
exits at 320x200x16. That clone used EGA fonts, CGA.GR2, standard mouse/sound
and empty Program Manager groups. It checks caps and normal exit, not new
full rendering or DOS-box coverage. See the companion NATIVE.JSN record.
