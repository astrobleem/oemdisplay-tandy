# Windows XT rc.6 qualification

rc.6 adds an original MIT static logo and a DOS mode menu with one-level
undo, interrupted-change recovery and Windows-active refusal. The seven
original XT Pixels fonts, display drivers, accepted Color wave and reservation
behavior are preserved. CGALOGO.LGO and Windows font setup media are no longer
needed. DOS/Windows, Setup, WIN.CNF, CGA.GR2 and other non-font components remain
owned inputs and are excluded from the new downloads.

RC6.JSON binds the exact source, runtime and package. The strict publisher
checks native preparation/default/VERIFY records, all five graphics GDI
results, actual Windows-launched DOS refusal, whole-install rollback and
the final 6402/TEXT Setup cases. RC6EV retains original evidence and failed
attempts; its historical checkpoint flags are not rewritten as success.
The accepted 6402 record corrects a host validator that required seven
actions even though the controller's six required phases completed. A later
repeat timeout remains a failed attempt. TEXT Setup acceptance is not a
claim that its known renderer corruption is fixed.

PREPXT's native base was compiled and executed in the bounded emulator
lease. DOCPINS/REBIND.PY then refreshes only four documentation pin rows.
It derives table boundaries from the preserved linker map, verifies all
59 rows and reproduces the current helper exactly. MZ header, relocations,
executable code, paths and other data are unchanged. The refreshed helper
was not rerun in a guest. The published package includes subsequent host
documentation and source updates; its exact hashes are bound separately.

Local host checks passed for font reproduction, saved native ANSI/OEM
coverage, FAT12, package reproducibility, 335 mode transaction checks,
1,890 copy/ownership fault checks, actual launcher emission and 12
publication rejection cases. The 361-byte static module reproduced exactly
with the explicit existing host assembler/linker. CI repeats the portable
release suite on Ubuntu, including the existing Linux-only shell tests.
No additional emulator is launched by the publication workflow.

Native screenshots in docs/FONTS and the previews ZIP are genuine saved
emulator captures; generated font specimens and HOST640.PNG are host renders.
160-pixel stock dialogs can clip and small menus can wrap. Physical hardware
is unqualified; recorded emulator host timings are not 8088 timing estimates.

The new source ZIP uses an explicit checked file list. GitHub's new tag
source archives omit historical binary ZIP bundles via export-ignore because
one legacy archive contains owned Windows support. Historical files, history,
tags and previous releases are preserved. No private compiler, Windows,
grabber or emulator bytes are added to this release.
