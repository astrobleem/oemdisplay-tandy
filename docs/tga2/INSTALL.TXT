TANDY VIDEO II - WINDOWS 3.0 REAL MODE, 640x200, 16 COLORS

For the Tandy 1000 SL/2 family with normal 640 KB RAM and an existing
Windows 3.0 installation. Do not use on EX/HX: they have no Video II.
T2RESV checks memory, not the Video II model. Testing covers the emulated
SL/2; physical machines and related SL/TL/RL models remain unqualified.

INSTALL
1. Extract the entire packet to C:\T2EXP. Exit Windows to plain DOS.
   The packet includes its fonts, grabber and startup logo. You do not need
   to collect Windows support files or run PREPINF.
2. From DOS text mode 3, run:
     C:\T2EXP\T2RESV
   Continue only after it succeeds. Then:
     C:
     CD \WINDOWS
     SETUP
   Choose Display / Other (disk supplied by a hardware manufacturer), enter
   C:\T2EXP and select:
     EXPERIMENTAL TANDY SL/2 FAMILY ONLY 640x200x16
   Choose Complete Changes. Keep your existing keyboard and mouse choices.
3. Before every Windows start, including after reboot, run:
     C:\T2EXP\T2RESV
   After it succeeds:
     C:
     CD \WINDOWS
     WIN /R
   Run T2RESV before Setup and before WIN /R, outside a Windows DOS box.
   Use your Windows directory in these commands if it is not C:\WINDOWS.

Setup selects the bundled XTCSYS.FON, XTCFIX.FON and XTCOEM.FON original
XT Pixels fonts, the CGA.GR2 grabber and XTSTATIC.LGO/WXTSPL01.RLE startup
logo. The driver, reservation helper and diagnostic programs are unchanged.

OPTIONAL TROUBLESHOOTING
PREPINF checks that the required packet files are present; it copies and
installs nothing. If one is missing, extract the complete packet again.
For another staging path, change the [disks] a= path in OEMSETUP.INF and
provide that same path to Setup.

To select another display, exit Windows, run T2RESV successfully and use
Setup. Reboot afterward to remove the resident reservation.
T2PROBE /W, T2MODES and T2SHOW are optional hardware diagnostics. Technical
records: https://github.com/astrobleem/oemdisplay-tandy/blob/main/docs/TGA2.MD
Component notices are in NOTICE.TXT and FONTLIC.TXT.
