TANDY VIDEO II - WINDOWS 3.0 REAL MODE, 640x200, 16 COLORS

DOWNLOAD
https://github.com/astrobleem/oemdisplay-tandy/releases/download/experimental-video-ii-2026-10-14-r2/TNDYV2.ZIP

For the Tandy 1000 SL/2 family with normal 640 KB RAM and an existing
Windows 3.0 installation. Do not use on EX/HX: they have no Video II.
T2RESV checks the memory layout, but cannot identify Video II or distinguish
an EX/HX from an SL/2. Related SL/TL/RL models and physical hardware are
unqualified; the recorded Windows runs use 86Box's SL/2.

INSTALL
1. Extract all ZIP files to C:\T2EXP. Exit Windows completely to plain DOS.
   These instructions use C:\WINDOWS; use your Windows path if different.
2. Prepare the Windows support files with the included helper:
     C:
     CD \T2EXP
     PREPINF C:\WINDOWS
   Continue only after it says:
     Prepared six owned Windows 3.0 support files.
   PREPINF searches your Windows SYSTEM folder and then its root. It only
   stages files; it does not install the driver or identify Windows versions.
   Supply matching Windows 3.0 files, never Windows 3.1 files.
3. From DOS text mode 3, run:
     C:\T2EXP\T2RESV
   Continue only if it succeeds. Then:
     CD \WINDOWS
     SETUP
   Choose Display / Other (disk supplied by a hardware manufacturer), enter
   C:\T2EXP, and select:
     EXPERIMENTAL TANDY SL/2 FAMILY ONLY 640x200x16
   Choose Complete Changes. Keep your existing keyboard and mouse choices.
4. Before every Windows start, including after reboot, run:
     C:\T2EXP\T2RESV
   After it succeeds:
     C:
     CD \WINDOWS
     WIN /R
   Always run T2RESV before Setup and before WIN /R, outside a Windows DOS box.

TROUBLESHOOTING
If PREPINF reports an existing support file or a copy failure, extract the
packet into a fresh staging folder and retry. Do not continue after an error.
If files are missing, obtain the matching files from your Windows 3.0 media.
Manual staging is an alternative: copy these six files into C:\T2EXP:
  CGA.GR2  CGALOGO.LGO  CGALOGO.RLE
  CGASYS.FON  CGAFIX.FON  CGAOEM.FON
For a staging path other than C:\T2EXP, change the [disks] a= path in
OEMSETUP.INF and give Setup that same path.

To change back, exit to plain DOS, run T2RESV successfully, then use Windows
Setup to select the previous display. Reboot afterward to remove T2RESV's
resident reservation. If Windows cannot start, run Setup from plain DOS.

OPTIONAL HARDWARE DIAGNOSTICS AND TECHNICAL RECORDS
T2PROBE /W and T2MODES report the memory mapping and BIOS modes. T2SHOW draws
16 color bars only after T2RESV succeeds. BIOS mode 0Ah alone is not this
640x200x16 mode. Hardware investigation and exact test scope are documented at:
https://github.com/astrobleem/oemdisplay-tandy/blob/main/docs/TGA2.MD
QUALIFY.JSON records rendering, reservation and maintenance-Setup tests.
Fresh Windows installation and DOS-box switching remain unqualified.
Component notices are in NOTICE.TXT.
