Private test media for docs/PCJR.MD "Clean Windows 3.0 installation".
Not in this repository.

Source: PCjs Windows 3.00 1.2 MB diskettes, repository
https://github.com/jeffpar/pcjs-diskettes at commit
cd3433748b09837a4c60ca7066f3642772b2d711, pcx86/sys/windows/3.00/.
These are the five 1.2 MB distribution diskettes (volumes WIN30DISK01-05)
listed on https://www.pcjs.org/software/pcx86/sys/windows/3.00/, the PCjs
page the browser workshop links. The workshop's own pinned upstream image
is a different file (Foxlum pcjs-wiki PCDOS320-WIN300-EGA.json, an
installed PC DOS 3.20 + Windows 3.0 hard disk); it has no Setup disks and
was not used. Version: Windows 3.00 (files dated 1990-05-01).
